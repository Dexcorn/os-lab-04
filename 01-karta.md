## 1.фрагмент pmap $$ с пояснением какие области видны

bash - исполняемый файл

r, w, x, s - права доступа 

LC... - файлы локализации

libc.so.6 - библиотека языка C

libtinfo.so.6.5 - библиотека для работы с терминалом

[ anon ] - участки памяти, не привязанные к конкретным файлам на диске

[ stack ] - область памяти, которая выделяется для каждого процесса

gconv-modules.cache - кэш модулей конвертации кодировок

ld-linux-x86-64.so.2 - это динамический загрузчик
